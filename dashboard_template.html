Keyboard Shortcuts

  • R - Refresh data
  • S - Open settings
  • H or ? - Show help
  • Esc - Close modals
  • F - Focus filter section

Chart Controls

  • Click ⚙️ on any chart to open customization options
  • Use Top N slider to limit displayed items
  • Change chart type (bar/line/pie/doughnut)
  • Select different color schemes
  • Toggle labels and animations
  • Export individual charts as images

Filters

  • Use dropdowns to filter by module or project
  • Set min/max hours to filter by time spent
  • Quick filter buttons for common views

Settings

  • Theme: Light, Dark, or Auto (follows system)
  • Layout Density: Compact, Comfortable, or Spacious
  • Font Size: Small, Medium, or Large
  • All settings are saved automatically
